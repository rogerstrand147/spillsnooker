# spillsnooker.no

Nettsiden «Snooker i Norge — hvor du kan spille». En enkel oversikt over
hvor i landet du kan spille snooker, med klubbkort, kulestripe, teller og
spilleliste.

## Innhold

Hele siden ligger i `index.html`. Det finnes ingen byggeprosess — fila
publiseres som den er via GitHub Pages.

## Klubbdata

Klubbdataene skal på sikt hentes fra et delt regneark, slik at klubbene
kan holde sin egen informasjon oppdatert. Regnearket er ikke satt opp ennå;
inntil videre ligger dataene direkte i `index.html`.

## Eierskap

Repoet skal overføres til en klubb når koalisjonen har valgt hvem som
skal eie det.
